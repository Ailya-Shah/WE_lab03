# Ailya Shah — Personal Portfolio

CS313: Web Engineering — Lab 3: HTML Advanced (Personal Portfolio II)

## About

A 5-page personal portfolio website built with plain HTML and a single external
CSS file. Layouts (navigation menu, home page bio/photo, hobby cards, skill
cards, and the image gallery) are arranged using CSS `float` and `clear`,
no JavaScript and no CSS frameworks.

## Pages

- `index.html` — home page with bio, education stats, and quick links
- `hobbies.html` — personal hobbies and interests
- `skills.html` — technical skills grouped by confidence level, plus languages
- `gallery.html` — image gallery of past project screenshots
- `contact.html` — email and social links
